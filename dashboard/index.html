Tunnel Twiddle Control

Letakkan robot di tempat permulaan terowong. Klik Start Next Trial. Robot akan dipandu menggunakan PID eksperimen secara automatik. Skrip akan mengira perbezaan jarak kiri/kanan dinding selama 15 saat.

Jika robot terlanggar dinding (<15cm), sistem akan terbatal secara automatik dan merekod markah penalti.
